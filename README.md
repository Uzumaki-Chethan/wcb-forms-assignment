# Diona Technologies — Forms & AI Intern — Round 2 Assignment

This repository contains two HTML/CSS/JavaScript implementations based on the two WCB Manitoba reference PDFs supplied as part of the Diona Technologies Round 2 screening assignment.

## Exercises

| Exercise | Reference Document | Folder |
|---|---|---|
| 1 | Medical & Travel Expense Request | `exercise1-medical-travel-expense/` |
| 2 | Worker Progress Report | `exercise2-worker-progress-report/` |

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- No frontend framework
- No build step
- No external backend required
